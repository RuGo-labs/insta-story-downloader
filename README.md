
# 📸 Instagram Story & Reel Downloader

A lightweight, multi-language CLI tool written in Python to download Instagram Stories and Reels seamlessly.

---

## ⚡ Features
- 🚀 Automatic requirement check and setup (`start.py`)
- 🌐 Multi-language UI support (**English**, **Russian**, **Chinese**)
- 🎨 Colorful terminal user interface
- 🔒 Authentication support via `cookies.txt` for private stories/content
- 🛡️ Clean output with suppressed raw technical tracebacks

---

## 📋 Requirements
- **Python 3.8+**
- `yt-dlp`
- `colorama`

---

## 🚀 Quick Start

1. **Clone the repository:**
```bash
git clone https://github.com/RuGo-labs/insta-story-downloader.git
cd insta-story-downloader

```

2. **Run the application:**
```bash
python start.py

```


> `start.py` will automatically check and install missing dependencies (`yt-dlp`, `colorama`) on first launch.



---

## 🍪 Instagram Stories Setup (`cookies.txt`)

Downloading Instagram Stories requires authentication.

1. Install the **Get cookies.txt LOCALLY** browser extension.
2. Log in to Instagram in your browser and export your cookies.
3. Save the exported file as `cookies.txt` in the root folder of this project.
